# Vulpes Studios — sitio web

## Cómo abrirlo
1. Extrae la carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Para editarlo, abre la carpeta en Visual Studio Code.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño, colores, responsive y animaciones.
- `script.js` — menú móvil y ventanas de eventos.
- `assets/` — coloca aquí el logo, banners e imágenes.

## Personalización rápida
- Cambia el enlace de Discord buscando `https://discord.gg/hQHU4scpgE`.
- Cambia textos y eventos directamente en `index.html`.
- Los colores principales están al principio de `style.css`, en `:root`.

## Publicarla
Puedes subir estos archivos a un hosting estático o a tu propio hosting con dominio.
